# Справочник паттернов BingX AltBullet

> Последнее обновление: 27.07.2026. Все условия выверены построчно против кода.

**Обозначения:**

- **OI** — открытый интерес (Open Interest, CoinGlass)
- **volMult** — фьючерсный объём BingX / 20-свечное среднее
- **spotVolMult** — спотовый объём BingX / среднее (приоритетнее фьюч. объёма)
- **SpotCVD** — накопительная спотовая дельта покупок/продаж (CoinGlass, ТФ: 30m/1h/4h)
- **FutTaker** — netBuyPct фьючерсных тейкеров (агрегировано по биржам)
- **price24h / price3h / price1h / price4h** — изменение цены за соответствующий период
- **cycleCount** — кол-во циклов подряд (~10 мин каждый) токен в пуле сканирования
- **fail-open** — если данные недоступны (null), гейт не блокирует

## ⚡ СКАЛЬП / РАЗВОРОТ (< 2ч)

### 1) 💥🔄 `liquidation_cascade` — Каскад ликвидаций → разворот _(Layer 10)_

- **Источник:** `liq-cascade-watcher.ts` (каждые 3 мин, независимо от основного скана)
- **Вход в пул** (окно 12 ч, дедуп 12 ч):
  - `liq_spike` — longLiq1h/longLiq24h ≥ **25%** + longLiq1h > **$50K** + price24h ≤ **5%**
  - `liq_order_stream` — ≥ **3** long-liq ордера ≥$10K за **15 мин** (ранний триггер, мин. сумма $30K)
- **liqExhausted** (обновляется каждые 3 мин):
  - `true` — longLiq1h < 30% от пика при обнаружении → каскад выдохся ✓
  - `false` — каскад ещё идёт (≥30% пика) ИЛИ longLiq1h=0 при обнаружении → **стоп**
  - `null` — CG недоступен → ждём следующего цикла (fail-closed; не стреляем вслепую)
- **Гейт выстрела** (`_runLiqCascadeFireCycle`, каждые 2 мин):
  - liqExhausted строго `true`
  - pool ≥ 30 мин (если liq_spike; liq_order_stream без этого ограничения)
  - price24h не обвал (< −50%)
  - OI 30m > **1.5%** или null (fail-open)
  - **CVD 4h не false (27.07.2026, fail-open):** CG доступен + cvd4h=false → блок. ДАННЫЕ: 79% отменённых сигналов (27/34 с данными) имели cvd4h=false; null/unavailable → проходит
  - CVD 30m не false (fail-open)
- Выход: **прямой сигнал**, стоп **−10%** (PATTERN_MAX_STOP)

> 📊 Бэктест 90д: в сборе (88 закрытых на 27.07; A=14, B=11, C=19, D=44 — 50% cancel)

### 6) ⚪ `stealth_breakout` — Пробой из тихой зоны _(Архетип E, ~12.7%; откалиб. 27.07.2026)_

- **Тестовый технический режим:** в сигнале оставлены только три слоя распознавания пробоя:
  - 4H: локальное кластерное сопротивление с достаточным качеством/touches и quiet-zone; уровень замораживается при ARMED
  - 4H: только свежая **закрытая** свеча, которая решительно закрылась выше frozen resistance
  - 30m: пост-4H refinement — вход остаётся рядом с уровнем, ожидает retest/reject и не допускает поздний вход
  - 1H: только необязательный контекст/телеметрия; 1H-only cross не является gate
- OI, CVD, Spot Taker, futures/spot volume, funding, SNF, `price24h` и `cycleCount` сейчас только сохраняются в диагностике и не блокируют тестовый сигнал
- Цель режима: сначала собрать фактическую выборку того, как технический детектор распознаёт пробои; подтверждения будут калиброваться после наблюдения
- Выход: **прямой сигнал**, стоп **−5%**

PDB: `stealth_breakout` — resistance 4H / closed breakout 4H / refinement 30m / `technical_gate_unmet`

### 8) 💫 `price_led_momentum` — Цена лидирует без OI _(Архетип C; добавлен 30.07.2026)_

**Что:** Цена уже движется вверх, но фьючерсный открытый интерес (OI) не разогрет. Спот-покупатели ведут ход. Пример: EPIC-USDT в прошлом — price24h +5–20%, oi4h < 4%, SNF > 0, WI > 0, ≥2 CVD.

**Условия входа:**

- price24h: **5%…40%** (значимое движение, не перегрет)
- price3h ≥ **1.5%** (цена активно растёт прямо сейчас)
- OI30m **< 2.0%** или null (OI не взрывной — цена ведёт без фьючей)
- OI4h (prescan `lastOi4h`) **< 4.0%** или null (фьюч-участие слабое)
- **SNF1h > 0 ИЛИ SNF4h > 0** (`getSpotNetflowEntry` — spot net flow положительный)
- **Whale Index > 0** (`lastWhaleIndex` из prescan_tracker — умные деньги внутри)
- **≥ 2 из** `[CVD15m, CVD30m, CVD1h, CVD4h]` = true (CVD спот-подтверждение)
- ⚠️ `cycleCount` НЕ является gate — паттерн ловит раннее ценовое движение
- Байпас anyOiPass + volume filter bypass (\_isArchetypeBypass)

**Стоп:** **−8%** (PATTERN_MAX_STOP), no-touch **2ч**

### 9) 🐋🎯 `whale_alert` — Кит открыл лонг (Hyperliquid, Layer 11) _(обновлено 27.07.2026)_

- **Источник:** CoinGlass Hyperliquid whale-alert лента (джоб каждые 3 мин)

- **Пул** `whale_alert_pool`: окно **24 ч**; повторные киты по тому же символу агрегируются; **per-symbol кулдаун 24 ч** после файра — следующий кит по тому же символу не создаёт новой записи. ДАННЫЕ: HYPE-USDT ×9 и SOL-USDT ×5 за 6 дней = 56% всех отмен паттерна (27.07.2026)
- **Гейт выстрела** (`_runWhaleAlertFireCycle`, каждые 3 мин):
  - price24h ≤ **20%** (рынок не знает раньше кита)
  - priceChange от whale entry ≥ **−1%** (не просел до выстрела)
  - **Cooldown по адресу кита:** тот же whale address закрывал позицию < **4 ч** назад → skip
  - **Liq proximity:** цена в пределах **8%** от liqPrice кита → skip (fail-open если null)
  - per-token Whale Index < **−100** → skip (fail-open)
  - **OI подтверждение:** OI30m ≥ **1.5%** ИЛИ OI1h ≥ **2.0%**
  - Альтернатива: FutTaker netBuyPct ≥ **10%** + SpotCVD1h positive

- alphaScore: база 6; +1 если позиция ≥ $5M ИЛИ оба лимитника подтверждены
- Выход: **прямой сигнал**, одноразовый; **whale-профиль** (firstTarget 8% / trailingActivation 12% / trailingGap 7%)
- Стоп: **−8%** max (PATTERN_MAX_STOP); min стоп **−4%** (не ставить ближе шума)
- No-touch stop: **4 ч** от входа
- Max watch: **14 дней** (кит входит рано, движение через 1–3 нед)

## Общие защитные гейты

- **Перегрев/обвал:** price24h > +40% или < −40% → исключается из всех слоёв (кроме watchlist)
- **Stale-cancel:** активный сигнал автоотменяется через **3 ч**, если пик прибыли не достиг **2%**
- **Cooldown:** 4 ч на повторный сигнал по одному токену; 12 ч после stop_loss
- **whale_alert per-symbol cooldown:** 24 ч после файра — новый кит по тому же символу не создаёт записи в пуле (персистируется в БД, переживает рестарты)
- **Smart cancel** (не раньше 4 ч от входа): OI+Taker оба в минус → cancel_reason=smart_cancel_oi_taker
- **Stop-loss:** FastCycle watcher (~2 мин). Не биржевой ордер — при резком проскальзывании фактическое закрытие может быть хуже заявленного порога

## 🔒 Unlock Filter

| Сценарий           | Условие                                       | Действие                                  |
| ------------------ | --------------------------------------------- | ----------------------------------------- |
| **Блок**           | Разлок ≤ 3 дней + ≥1% supply + не в watchlist | Символ пропускается (`gate=unlock_block`) |
| **Предупреждение** | Разлок 4–7 дней + ≥1% supply                  | Сигнал проходит + строка в Telegram       |
| **Watchlist**      | Любой разлок                                  | Только предупреждение если 4–7 дней       |
| **Нет данных CG**  | API недоступен                                | **Fail-open**                             |

- Кэш: 4 часа. Источник: CoinGlass `coin-unlock-list`.
