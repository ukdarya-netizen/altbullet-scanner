## Источники и SQL

Новые запросы к production в этом дополнении не выполнялись; использованы локальные результаты прежних read-only SELECT в `reports/.cache/stealth-final-1127-input/` и исходный архив событий `reports/stealth-final-1127/data-exports.tar.gz`. Зафиксированный SQL для fired signals (из `reports/stealth-final-1127/production-selects.sql`):

```sql
SELECT encode(convert_to(row_to_json(t)::text, 'UTF8'), 'base64') AS b64
FROM tracked_signals t
WHERE t.sentiment_key = 'stealth_breakout'
  AND t.detected_at >= $1::timestamptz
  AND t.detected_at <= $2::timestamptz
  AND t.id > $3
ORDER BY t.id
LIMIT $4;
```

Цены — только закрытые BingX свечи; для индикаторов учитывались бары, закрывшиеся не позже закрытия пробойной 4H-свечи. Все расчёты разрывались на непрерывных сегментах cache, поэтому отсутствие периода не сжималось в более короткий временной интервал. Пустые поля имеют индивидуальную колонку `_missing_reason`.

## Расчёт метрик

- Bollinger(20,2): стандартное отклонение population; `%B` записан на шкале 0–100. Percentile сравнивает ширину breakout bar с предыдущими 50 барами; minimum width — предыдущие 20 баров.
- ATR14/ATR50 и ATR20 — Wilder; Keltner(20,1.5×ATR20); squeeze — BB целиком внутри Keltner; счёт за текущий и 19 предыдущих закрытых баров. Диапазон 4H использует предыдущие 6/12/30 баров, не breakout candle.
- Относительный BTC: доходность монеты минус BTC в процентных пунктах по синхронным 4H close (4ч, 24ч, 7д, 30д); отношение coin/BTC к EMA20/50 рассчитано по синхронным close.
- Stochastic(14,3,3), StochRSI(14,14,3,3), Supertrend(10,3), Ichimoku(9,26,52) с облаком на 26 баров назад без lookahead. Williams fractal подтверждён только после двух правых закрытых свечей; divergence сравнивает последние два подтверждённых lower fractals. Alligator использует SMMA median(13/8/5), shifts 8/5/3. AO=SMA5−SMA34; Williams %R14.
- `passes_12pct` повторяет `neonLevelRiseFrom24hLowPct`: последняя из 6 свечей 4H — пробойная, rise = close / min(low этих свечей) − 1.
- `days_since_last_daily_close_above_zone_top`: от последнего закрытия 1D выше `zone_top`; `4h_zone_touch_below_top_count_30d`: предшествующие 30д 4H свечи, пересёкшие диапазон зоны и закрывшиеся ниже верхней границы. Если уровни зоны не сохранены — пусто с причиной.

В отчёте нет лимита числа сигналов и временного выхода сверх текущей 4-дневной политики.
