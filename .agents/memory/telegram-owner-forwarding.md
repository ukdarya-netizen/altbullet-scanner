---
name: Telegram forwarding policy
description: Политика пересылки сообщений Telegram-канала, бота и owner-копий.
---

Все сообщения Telegram — публикации канала, личные сообщения бота и
operational owner-копии — отправляются без `protect_content`, поэтому любой
получатель может их пересылать и сохранять. Owner остаётся отдельным вечным
получателем только для маршрутизации, не для отличающейся защиты контента.

**Why:** Пользователь явно выбрал свободную пересылку для всех получателей,
включая владельца. Настройка задаётся Bot API на каждом сообщении, а не только
на уровне настроек Telegram-канала.

**How to apply:** Все общие text/photo/file-id пути должны явно отправлять
`protect_content: false` и не принимать вызываемый override, способный вернуть
защиту только для части аудитории. Определять owner-а только по настроенному
числовому chat ID; `@username` не является надёжным адресом приватного чата.
