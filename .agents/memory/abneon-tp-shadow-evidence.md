---
name: ABNeon TP shadow evidence
description: Правила доказательности для наблюдательного эксперимента тейков ABNeon.
---

Исторические тестовые цели ABNeon остаются только для аудита; новые ABNeon TP-shadow наблюдения и цели не создаются. Они всегда были отделены от реальных торговых целей и не меняли stop, BE, trailing, Telegram или terminal status.

TP-before-terminal считается доказанным только при подтверждённой записи live-наблюдения до закрытия. Если sampled/DB-наблюдение отсутствует, terminal outcome должен быть `ambiguous`, а не `terminal_before_target`: между опросами могло быть внутриминутное касание.

Исторический `peak_price >= target` без точного event-time также остаётся `peak_reached_order_unknown`.

**Why:** двухминутный FastCycle и исторический peak не доказывают порядок TP и SL; ложные отрицательные исходы исказят калибровку сильнее, чем честно неполная coverage.

**How to apply:** Не возобновлять этот эксперимент без отдельного решения пользователя. При анализе архивных записей отсутствие hit никогда не трактовать как проигрыш цели; для будущего эксперимента нужны event-time наблюдения и отдельная политика, не затрагивающая действующие выходы.
