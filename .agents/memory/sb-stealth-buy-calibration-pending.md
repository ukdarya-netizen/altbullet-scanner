**Статус (2026-08-13):** profit n=3 — ни gate, ни soft-penalty не реализуем. Ждать минимум 5-7 profit сигналов.

**Наблюдения по имеющимся данным (n=3 profit, общий n не задокументирован — пересчитать при следующем анализе):**
- WI: в profit-группе — в ожидаемую сторону (выше нуля)
- OI30m: profit ниже SL — ожидаемое направление (сигналы без разогрева OI лучше)
- cycles: profit-группа дольше в prescan — аналогично BA/BG, паттерн консолидации
- funding: profit-группа ближе к нейтральному/негативному — ожидаемое направление

**Почему не реализуем:**
- n=3 в profit-группе — любой порог калиброван на 1-2 выброса, а не на реальный edge
- Любая из этих метрик может инвертироваться при следующих 2 сигналах
- Правило проекта: soft-penalty только при n≥10+ в profit-группе, hard gate — только при сильных данных n≥15+

**Следующий шаг:** при накоплении 5-7+ profit сигналов — пересчитать распределения по каждой метрике и принять решение по soft-penalty. Первыми кандидатами проверить WI и OI30m.
