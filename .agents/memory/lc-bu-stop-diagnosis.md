**Диагноз (2026-08-13, не требует реализации):**

Паттерн bu_stop у `liquidation_cascade`: сигнал с WI позитивным (киты покупали) и spot_taker негативным (розница продавала) — доходит до +5–8%, затем откатывается.

**Механика:**
- WI > 0 = киты входили в лонг → цена разгоняется (+5–8%)
- spot_taker < 0 = розница продавала против → не подхватывает движение
- Без розничного участия лонг кита иссякает → откат

**Почему не гейт сейчас:**
- n слишком мало для hard-reject
- WI > 0 блокирует existing hard-block (`WI < 0 + CVD4h=false`)
- Паттерн "купил, частично прав, но не хватило follow-through"

**How to apply:**
- Не блокировать. Наблюдать в данных entry_whale_index + entry_spot_taker_net_buy по LC закрытым сигналам
- Когда накопится n≥20 bu_stop случаев с WI>0+spot_taker<0 — пересчитать отдельно

**Когда вернуться:** после ~3–4 недель новых LC-сигналов (ожидаемый объём при текущем ритме — октябрь 2026)

## Аудит порога B.U. (2026-08-24)

Порог B.U. для `liquidation_cascade` пока остаётся на +5%. Production-аудит
выявил 28 B.U.-выходов: 23 из них закрылись после максимума до +8%, а только
7 дошли до +8% и 2 — до +10%. Повышение порога сейчас убрало бы защиту у
большинства этих сделок, не имея достаточной проверки того, что они затем
восстанавливаются.

Почасовая 72h-траектория заполнилась только у двух зрелых B.U.-сигналов:
один продолжил рост до +48.6% после выхода, другой — до +9.8%. Это важный
сигнал, что B.U. на +5% иногда преждевременен, но n=2 не позволяет обосновать
ни +8%, ни +10%.

**Why:** после-B.U. траектории начали записываться только недавно, поэтому
старые зрелые B.U. не имеют данных, нужных для честного сравнения порогов.

**How to apply:** не менять порог до появления как минимум 10 зрелых LC
B.U.-сделок с ≥60 почасовыми наблюдениями в первые 72 часа после закрытия.
Тогда сравнить долю продолжений ≥8% и ≥10%, а не только цену на 72-м часу.
