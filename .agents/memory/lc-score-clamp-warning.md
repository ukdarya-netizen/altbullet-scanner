---
name: LC alpha score — 5 независимых штрафов при clamp=2
description: Предупреждение о потере разрешающей способности числового score после добавления 5-го штрафа −2.
---

**Правило:** Score LC = 6 базовый − N×2, clamp=Math.max(2, ...).

**Текущие штрафы (по состоянию на 2026-08-13, все реализованы):**
1. OI24h < 10% → −2
2. CVD4h = false → −2
3. liq1h < $60k → −2
4. spot_taker < 0 → −2
5. ob_ratio > 1.2 → −2

**Проблема:**
После clamp=2 score=2 означает "хотя бы 2 штрафа сработало". Нельзя различить "2 проблемы" от "5 проблем" по числу. Информация остаётся только в тексте `scoreBreakdown`.

**Why:**
Линейный вычет с жёстким полом уничтожает ранжирование при количестве штрафов > (base - clamp) / step = (6-2)/2 = 2. После 2-го штрафа score=2 у всех "плохих" кандидатов независимо от того, сколько именно условий сработало.

**How to apply:**
- Не добавлять 6-й штраф −2 без пересмотра схемы. Варианты при необходимости:
  a) Снизить clamp с 2 до 0 (score может стать 0 = полностью не рекомендован)
  b) Перейти на мультипликативную шкалу (score *= 0.7 за каждый штраф)
  c) Добавить отдельный уровень "low_confidence" флаг вместо числа
- scoreBreakdown текст остаётся читаемым и информативным — это единственный источник детализации при score=2.
